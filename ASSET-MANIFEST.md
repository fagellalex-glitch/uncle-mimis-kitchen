source. Base of original URLs: `https://unclemimi.weebly.com`.

`editmysite.com`, or any Weebly CDN/query‑string URL.

## Notes

- Full‑resolution originals are preserved in `raw/` and `public/assets/images/`.
- PNG product screenshots (1–2 MB each) were re‑encoded to optimized JPEG for the
  web; the lossless PNG originals remain in `raw/`.
- Modern formats (WebP/AVIF) were **not** generated — no encoder was available in
  the build environment. See README → "Adding WebP/AVIF".
